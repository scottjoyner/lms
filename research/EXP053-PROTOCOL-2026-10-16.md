# EXP-053 pre-inference protocol: blinded RACE examination-source gate

**Frozen before selecting review items or running any K2/Qwen/MiniCPM model forwards. Research only; PRODUCTION NO-GO.**

- Public prior K2 experiments EXP036–052 used QASPER, QuAC, SQuAD and synthetic author-created data; RACE examination test articles constitute a distinct corpus, but are **not guaranteed unseen in pretraining**. Exact normalized text hashes are checked against prior local corpus excerpts where feasible.

## Selection frozen before logits

- Sort source group IDs by SHA256 of `EXP053-RACE-HIGH-TEST-v1|example_id`; take first **64** eligible distinct articles, one question chosen per article by SHA256 of fixed seed + question/options text, without looking at answer text correctness or model outputs.
- Eligibility before selection: question 15..230 characters, article 250..3500 characters, exactly four nonempty distinct options each 1..160 chars, answer in A–D. This is a candidate packet (64 items); **at least 40 reviewer-accepted articles** required before evaluation.
- Any item dropped at human review is logged as a blinded review rejection, not secretly replaced; if <40 pass, freeze a distinct extension protocol before making a new cohort.
- Hash exact dataset bytes, selected source IDs, questions, options, prompts, original examination key and corpus version. Public manifest must contain only hashes, lengths, source-ref opaque IDs, item count, seed and license link.

## Independent blind review — mandatory before model forwards

- Emit two separate *locally held* reviewer packets **without the gold key or model predictions**, with four options deterministically permuted per case. Two independent human reviewers must each attest to the passage and question, select one uniquely supported option, select one plausible-but-unsupported foil, and quote an exact contiguous source sentence showing the supported answer; any non-literal inference requires an explicit explanation and reviewer rejection/rewrite.
- Reviewers must not see each other's annotations or model outputs. Agreeing labels must equal the sealed original human exam key after unblinding. Any difference goes to a separately verified third adjudicator; never manufacture human review labels, signatures, consensus or approval.
- Required Ed25519 signatures on canonical JSON reviewer submissions, pinned separately maintained public keys and distinct authorized signer IDs; fail closed on unsigned, duplicate signer, invalid signature, corpus/packet mismatch, unreviewed items, unsubstantiated source spans, or unlogged rejection.
- Evidence-switch, withheld passage, unrelated question, and label-rotation conditions are constructed only after the preregistered human-validated 40+ items are frozen. **RACE exam 'human-authored alternatives' alone does not constitute our own blinded adjudication.**

## Locked evaluation and inference controls

- Target models pinned by EXP051/052: K2-Horizon-3.7B, Qwen3.5-4B-Base, MiniCPM-V 4.7-1B. Different checkpoint type / tokenizer / chat alignment remain explicit factors.
- Primary outcomes: evidence-conditioned gold-versus-human-foil question×evidence interaction, incorrect-foil rejection, no-evidence abstention, strict free generation and evidence attribution. Compare paired article-level signs and cluster bootstrap intervals; prespecify multiplicity correction. Raw cross-model NLL magnitudes and CPU timings not directly comparable.
- Do not submit a new inferential significance claim with fewer than 40 reviewed independent articles, or run full native experiment on provisional/unreviewed data.
- Prior studies remain unchanged; no production routing, NAS/Neo4j writes, model checkpoint merges, training, promotion, deployment, or arXiv.
