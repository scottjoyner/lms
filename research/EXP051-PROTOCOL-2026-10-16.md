## Matched within-model question/evidence factorial
- Eight authored, artificially paired two-entity facts, all deliberately synthetic.
- Five cells per topic: supported question with original evidence; supported question with value-swapped evidence; unrelated unanswerable question with original evidence; unrelated question with swapped evidence; supported question with source withheld.
- Each cell receives both A/B option-label rotations; a third C = NOT STATED choice is fixed.
- Score logits for literal single-token `" A"`, `" B"`, `" C"` after identical answer prefix within each model.
- Strict correct = first-value label (original), second-value label (swapped), C (unrelated/withheld).
- Per-topic evidence switch: [logP(first)-logP(second)] original minus flipped.
- Question×evidence interaction: evidence switch for supported question minus switch for unrelated question.
- Require full 80 native forwards/model, all choice tokens one token, full 8-topic and 5-cell/2-rotation inventory, no partial success claims.
