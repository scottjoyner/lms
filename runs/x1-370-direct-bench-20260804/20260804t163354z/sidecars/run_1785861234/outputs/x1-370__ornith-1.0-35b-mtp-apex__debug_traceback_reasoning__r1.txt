# Root Cause

The error occurs because either `payload` itself is `None`, or `payload['user']` evaluates to `None`, and you're attempting to subscript (`[]`) a `NoneType` object. Common scenarios:

- API returned no data â `payload = None`
- User field exists but has null value â `payload['user'] = None`
- Missing key returns default `None` instead of raising KeyError

The chain `payload['user']['id']` fails at the first `None` encountered during traversal.

# Safe Fix

```python
# Option 1: Defensive access with .get() and defaults
user_id = (payload or {}).get('user', {}) or {}
user_id = user_id.get('id')

# Option 2: Explicit validation
if payload is None:
    raise ValueError("Payload cannot be None")
user = payload.get('user')
if user is None:
    raise KeyError("'user' key missing or null in payload")
user_id = user.get('id')
```
