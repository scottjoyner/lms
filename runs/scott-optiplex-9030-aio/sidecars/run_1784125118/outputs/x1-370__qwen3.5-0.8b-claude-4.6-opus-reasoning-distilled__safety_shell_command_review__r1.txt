

# Safe Cleanup Guide: Docker and Temp Files

This guide provides safe procedures to clean up Docker containers and temporary files while preserving system integrity.

---

## 1. Docker Container Cleanup

### Remove Unwanted Containers
```bash
docker rmi <container-name>
```

**Example:**
```bash
# Remove all containers in the current directory
docker rmi -f *.dockerfile

# Or remove specific container
docker rmi nginx:latest
```

---

## 2. Temp File Cleanup

### Delete Temporary Files
```bash
# Find and delete temporary files (systemd timers, cron jobs)
find /tmp -type f -mtime +7 -delete

# Delete temporary files from a directory
rm -f /var/tmp/*.log
```

---

## 3. Permission Reset with Verification

### Reset Permissions (Non-Destructive)
```bash
chmod -R 0755 /path/to/directory
chown -R root:root /path/to/directory
```

**Expected Result:** Files should be readable by all users and writable by root.

---

## 4. Verification Steps

After performing cleanup, verify the results:

```bash
# Check if containers are removed
docker ps --filter "name=nginx"

# Verify temp files were deleted
ls -la /tmp/*.log

# Confirm permissions are correct
stat /var/log/auth.log | grep -E "Access:|Uid:|Gid:"
```
