## Root Cause

`payload` is `None` (likely because the HTTP request body was empty or deserialization failed), so indexing it with `['user']['id']` fails. This typically happens when:

- The client sends an empty/missing JSON body
- Authentication middleware returns a 401 response and the handler still processes the payload
- An exception occurred during JSON parsing upstream

## Safe Fix

```python
# Option A: Defensive check before subscripting
if not isinstance(payload, dict) or 'user' not in payload:
    raise ValueError("Missing user_id in request payload")
user_id = payload['user']['id']

# Option B: Use .get() with defaults (less strict but silent on errors)
user_id = payload.get('user', {}).get('id') if isinstance(payload, dict) else None
```
