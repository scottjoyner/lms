## â Issue 1: Binding to `0.0.0.0` on port 8000

| Risk | Impact |
|------|--------|
| Service reachable from any network interface (including external) | Unauthorized access, data exfiltration |
| No transport-layer authentication by default | Credentials sent in plaintext unless TLS is added |

### Mitigation Checklist
- [ ] **Bind to `127.0.0.1`** for local-only access:  
  ```python
  uvicorn main:app --host 127.0.0.1 --port 8000
  ```
- [ ] If external access is required, use a **reverse proxy** (nginx/Caddy) with TLS termination and restrict upstream binding to `localhost`
- [ ] Add **authentication middleware** before any route handler:
  ```python
  from fastapi import HTTPException, Request

  async def require_token(request: Request):
      auth = request.headers.get("Authorization")
      if not auth or not auth.startswith("Bearer "):
          raise HTTPException(status_code=401, detail="Missing token")
      return await verify_token(auth[7:])
  ```
- [ ] Enable **HTTPS** with a valid certificate (certbot/letsencrypt)

## â Issue 2: CORS wildcard (`*`)

| Risk | Impact |
|------|--------|
| Any origin can read/write your API endpoints | Cross-origin data theft, CSRF exploitation |
| Combined with `credentials`, allows stealing session tokens | Full account takeover |

### Mitigation Checklist
- [ ] **Restrict CORS origins** to specific trusted domains:
  ```python
  from fastapi.middleware.cors import CORSMiddleware

  app.add_middleware(
      CORSMiddleware,
      allow_origins=["https://yourapp.example.com"],  # explicit list only
      allow_credentials=True,
      allow_methods=["GET", "POST"],
      allow_headers=["Authorization", "Content-Type"],
  )
  ```
- [ ] If you need dynamic origins (e.g., SPA), use a **whitelist stored in env vars**, not hardcoded wildcards
- [ ] Validate the `Origin` header server-side for any write operations

## â Issue 3: API token stored in README

| Risk | Impact |
|------|--------|
| README is typically public (GitHub, GitLab) | Token exposed to anyone with repository access |
| Tokens rotate slowly; exposure may persist indefinitely | Long-lived compromise window |

### Mitigation Checklist
- [ ] **Never store secrets in documentation or source files**
- [ ] Use a **secrets manager**: AWS Secrets Manager, HashiCorp Vault, Docker secrets, or environment variables at runtime:
  ```python
  import os
  API_TOKEN = os.environ["API_TOKEN"]
  ```
- [ ] If you need to pass tokens in CI/CD, use **encrypted env vars** or a dedicated secret injection tool (e.g., `sops`, `envsubst`)
- [ ] Rotate the token immediately if one was ever exposed
