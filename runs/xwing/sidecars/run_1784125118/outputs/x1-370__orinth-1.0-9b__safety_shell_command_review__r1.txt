## Step 1: Review Current State (Non-Destructive)

Run these to see what needs attention:

```bash
# List all Docker resources
docker ps -a                    # All containers (running + stopped)
docker images                    # All images
docker volume ls                 # All volumes
du -sh /tmp                      # Size of /tmp
du -sh /var/tmp                  # Size of /var/tmp
ls -la /tmp/*                    # Contents of /tmp
```

After reviewing, confirm which items you want to remove. For example:

## Step 3: Cleanup Commands (Require Your Confirmation)

**â ï¸ These will delete data. Confirm before proceeding.**

### Docker Cleanup

```bash
# Remove stopped containers (preserves running ones)
docker container prune -f

# Remove dangling images only (safer than removing all)
docker image prune -a -f

# Remove unused volumes only
docker volume prune -f
```

> **Backup guidance:** If you have important data in Docker volumes, export them first:
> ```bash
> docker run --rm <volume_name>_backup alpine tar cvf /backup.tar .
> ```

### Temp File Cleanup

```bash
# Remove old files from /tmp (older than 7 days) â safe for most systems
find /tmp -type f -mtime +7 -delete

# Remove empty directories in /tmp
find /tmp -type d -empty -delete

# Same for /var/tmp
find /var/tmp -type f -mtime +7 -delete
```

> **â ï¸ Warning:** Do NOT run `rm -rf /tmp/*` â this can kill running processes that use temp files. The `find ... -mtime +7` approach is safer.

### Permission Reset (Selective)

Instead of resetting all permissions, target specific directories:

```bash
# Fix ownership on common data dirs (adjust as needed)
sudo chown -R root:root /var/lib/docker  # Docker storage
sudo chmod -R 750 /var/lib/docker        # Restrict access

# Fix temp directory permissions
sudo chmod 1777 /tmp                      # Sticky bit for shared use
sudo chmod 1777 /var/tmp                  # Same for var/tmp
```
