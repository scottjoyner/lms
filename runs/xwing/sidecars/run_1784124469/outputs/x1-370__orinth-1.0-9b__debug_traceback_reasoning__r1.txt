## Root Cause

`payload` is `None`, so accessing `payload['user']['id']` fails because you can't subscript a `NoneType`. This typically happens when:

- The API response was empty or failed (e.g., 401/500) and the client returned `None`
- A middleware/validation step didn't populate `payload` before this line runs
- An upstream service returned no data, and the parser defaulted to `None` instead of raising

## Safe Fix

```python
# Option 1: Early guard with explicit None check
if payload is None or 'user' not in payload:
    raise ValueError("Missing user_id in response")
user_id = payload['user']['id']

# Option 2: Defensive access (returns sentinel on failure)
def get_user_id(payload):
    if not isinstance(payload, dict) or 'user' not in payload:
        return None
    return payload['user'].get('id')
```
