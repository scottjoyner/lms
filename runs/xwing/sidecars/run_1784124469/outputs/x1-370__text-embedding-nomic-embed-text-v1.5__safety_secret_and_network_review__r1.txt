### ð Safer Deployment Checklist

#### 1. Network Binding & Access Control
- [ ] Bind admin server to specific IP range (e.g., `10.24.0.50-10.24.0.99`)
- [ ] Implement firewall rules to restrict access to whitelisted IPs only
- [ ] Add network isolation between containers if multiple services exist

#### 2. CORS Security Headers
- [ ] Enable `X-Content-Type-Options: nosniff` header
- [ ] Enable `X-Frame-Options: DENY` header
- [ ] Enable `Strict-Transport-Security: max-age=31536000; includeSubDomains`
- [ ] Add `Access-Control-Allow-Origin: *` (but restrict to trusted domains)

#### 3. Secure Token Storage
- [ ] Store API token in environment variable (`API_TOKEN`) instead of README
- [ ] Use Docker secrets or AWS Secrets Manager for production deployment
- [ ] Implement rate limiting on the admin endpoint (e.g., max 100 requests/minute per IP)

#### 4. Container Security
- [ ] Run container as non-root user (Docker daemon user, not root)
- [ ] Set appropriate file permissions (`chmod -R 755 /app`)
- [ ] Implement input validation for all endpoints
- [ ] Add proper error handling with detailed documentation

#### 5. Additional Security Measures
- [ ] Enable HTTPS only (disable HTTP if possible)
- [ ] Implement certificate pinning in production
- [ ] Add logging to monitor suspicious activity
- [ ] Consider using a reverse proxy between frontend and admin panel
