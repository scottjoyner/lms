## Safer Deployment Checklist

### 1. Network Binding â Restrict Access
```python
# â Before: binds to all interfaces
uvicorn main:app --host 0.0.0.0 --port 8000

# After: bind only to localhost or a specific internal interface
uvicorn main:app --host 127.0.0.1 --port 8000
```
- If external access is required, use **reverse proxy** (nginx/caddy) with TLS termination and IP allowlisting
- Consider using `--interface eth0` only if you control the subnet

### 2. CORS â Restrict Origins Explicitly
```python
# â Before: allows any origin
from fastapi.middleware.cors import CORSMiddleware
app.add_middleware(CORSMiddleware, allow_origins=["*"])

# After: whitelist specific trusted origins only
app.add_middleware(
    CORSMiddleware,
    allow_origins=["https://your-app.example.com"],  # explicit list
    allow_credentials=True,
    allow_methods=["GET", "POST"],
    allow_headers=["Authorization"],
)
```

### 3. Secrets â Use Environment Variables or Secret Managers
```python
# â Before: token in README
API_TOKEN="sk-xxxxxxxxxxxxxxxx"  # NEVER do this

# After: load from environment at runtime
import os
api_token = os.getenv("API_TOKEN")

if not api_token:
    raise RuntimeError("API_TOKEN must be set via environment variable")
```

**Recommended secret management options:**
- Docker secrets (for containerized deployments)
- AWS Secrets Manager / GCP Secret Manager
- `.env` file **excluded from git** with a `.gitignore`:
  ```
  .env
  *.token
  credentials/
  ```

### 4. Container User â Drop Privileges
```dockerfile
