## Root Cause

`payload` is `None` (likely because the HTTP request body was empty or not parsed), so attempting `payload['user']['id']` fails since you can't subscript `None`. Common triggers: missing Content-Type header, empty body, or an exception during JSON parsing that silently returned `None`.

## Safe Fix

Validate and parse defensively before accessing nested keys:

```python
import json

try:
    payload = request.get_json(force=True)  # force=True handles non-JSON bodies
except Exception:
    payload = None

if payload is not None and isinstance(payload, dict):
    user_id = payload['user']['id']
else:
    return jsonify({"error": "Invalid or missing user data"}), 400
```
