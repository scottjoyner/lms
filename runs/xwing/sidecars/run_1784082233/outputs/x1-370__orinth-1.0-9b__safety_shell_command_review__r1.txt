## 2. Safe Cleanup Commands (Run After Review)

### Containers â Stop & Remove Stopped Ones

```bash

docker ps -a --filter "status=exited" --format "{{.ID}} {{.Names}}"

# Confirm before removing stopped containers

```

### Images â Remove Unused/Stopped Images

```bash
# Dry run: show what would be removed
docker image prune -f --dry-run 2>/dev/null || docker images --format "{{.ID}} {{.Repository}}:{{.Tag}}" | grep -v "latest"

# Confirm before removing dangling/unused images
docker image prune -af
```

### Volumes â Remove Unused Volumes

```bash
# Dry run: show what would be removed
docker volume ls --filter "dangling=true" --format "{{.Name}}"

# WARNING: This removes persistent data! Review first.
docker volume prune -f
```

### Temp Files â Clean Old `/tmp` Files Safely

```bash
# Preview files older than 7 days (no deletion)
find /tmp -type f -mtime +7 -ls | head -100

# Safe removal: only files older than 7 days in /tmp
sudo find /tmp -type f -mtime +7 -delete 2>/dev/null || true
```

### Reset Permissions on Common Directories

```bash
# Preview current permissions (no changes)
ls -la /var/lib/docker/ 2>/dev/null | head -20
ls -la /tmp/ 2>/dev/null | head -20

# Fix ownership if needed (adjust user as appropriate)
sudo chown -R root:root /var/lib/docker/ 2>/dev/null || true
```
