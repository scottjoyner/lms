### Root Cause
The error occurs because `payload['user']` evaluates to `None`. In Python, you cannot use square brackets (`[]`) to access keys on a `NoneType` object. This typically happens when the input data (like a JSON response) contains the key `"user"`, but its value is explicitly null.

### Safe Fix
Use the `.get()` method with a default empty dictionary `{}`. This allows you to chain lookups safely without raising an exception if a key is missing or null.

```python
# Safe approach: returns None if 'user' is missing or None, 
# and returns None if 'id' is missing.
user_id = payload.get('user', {}).get('id') if payload.get('user') else None

# Alternative (more concise if you just want a default value):
user_id = (payload.get('user') or {}).get('id')
```
