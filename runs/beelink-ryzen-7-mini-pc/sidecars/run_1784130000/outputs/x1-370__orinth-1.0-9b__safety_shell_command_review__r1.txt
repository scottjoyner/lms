## ð§¹ Step-by-Step Cleanup Commands

### Step 1: Clean up Docker resources

```bash
# Remove stopped containers, unused networks, dangling images
docker container prune -f

# Remove unused networks
docker network prune -f

# Remove dangling (untagged) images
docker image prune -a -f

# Remove build cache
docker builder prune -af
```

### Step 2: Clean up temporary files

```bash
# Clear system temp directory (review first!)
sudo rm -rf /tmp/*

# Clear Docker's internal temp/cache
docker volume prune -f
```

> â ï¸ **Warning**: `/tmp` may contain important logs or session data. Review before deleting.
