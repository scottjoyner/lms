

# Safe Docker & File Cleanup Commands

## Step 1: Backup Important Data First

Before cleaning, you should back up your important files:

```bash
# Create a full backup of your most critical data
sudo cp /home/yourusername/* /backup/
sudo cp /var/log/* /backup/
sudo cp /root/* /backup/
```

## Step 2: Clean Docker Containers and Temp Files

### Remove Docker containers (if not needed):

```bash
# Find all running containers
docker ps -a

# Stop unwanted containers
for container in $(docker ps -a --filter "name=.* && status!=running"); do
    sudo docker stop "$container" 2>/dev/null || true
done

# Remove stopped containers (if they're not needed)
sudo docker rmi $(docker ps -aq --filter "name=.*") 2>/dev/null || true
```

### Clean temporary files:

```bash
# Find and remove temp files
find /home/yourusername -type f -mtime +7 -delete 2>/dev/null || true
find /var/tmp -type f -mtime +7 -delete 2>/dev/null || true
find /tmp -type f -mtime +7 -delete 2>/dev/null || true

# Remove temporary directories
sudo rm -rf /var/tmp/*
```

### Verify cleanup:

```bash
# Check if containers are gone
docker ps --filter "name=.*"

# Check for remaining temp files
find /home/yourusername -type f -mtime +7 2>/dev/null || echo "No old temp files found"
```

## Step 3: Reset Permissions Safely

### Reset permissions to default (not destructive):

```bash
# Reset ownership and permissions on important directories
sudo chown -R yourusername/yourusername /home/yourusername
sudo chmod -R 755 /home/yourusername
sudo chown -R root:root /var/log
sudo chmod -R 755 /var/log

# If you want to reset permissions on specific files (with confirmation):
echo "=== Permission Reset Confirmation ==="
echo ""
echo "This will reset ownership and permissions of all files in your home directory."
echo "You can verify by running: ls -la /home/yourusername/"
echo ""
read -p "Do you want to proceed with permission reset? (y/n): " confirmation

if [ "$confirmation" = "y" ]; then
    echo ""
    echo "Resetting permissions for all files in /home/yourusername..."
    sudo chown -R yourusername/yourusername /home/yourusername 2>/dev/null || true
    sudo chmod -R 755 /home/yourusername 2>/dev/null || true
fi
```

## Step 4: Verify Everything Works

```bash
# Final verification
echo "=== Verification Report ==="
echo ""
echo "1. Containers:"
docker ps --filter "name=.*" | wc -l
echo ""
echo "2. Old temp files:"
find /home/yourusername -type f -mtime +7 2>/dev/null | wc -l
echo ""
echo "3. Permission status (should be 755):"
ls -la /home/yourusername/ | head -10
```

---

## Summary of Safe Actions:

| Action | Command | Notes |
|--------|---------|-------|
| Backup critical data | `sudo cp ...` | **Required** before cleanup |
| Stop unwanted containers | `docker stop <container>` | Use `-a` to see all running ones |
| Remove old temp files | `find -mtime +7 -delete` | Check first if you want to keep them |
| Reset permissions | `sudo chown -R ...; sudo chmod -R 755` | **Confirm before** with verification |
