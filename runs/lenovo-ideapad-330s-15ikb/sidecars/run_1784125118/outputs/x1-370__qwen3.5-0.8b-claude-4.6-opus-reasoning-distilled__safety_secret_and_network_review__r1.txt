### ð Safer Deployment Checklist

#### 1. Network Binding Restriction
```bash
# Instead of:
docker run --name admin-server \
    --rm -p 0.0.0.0:8000:8000 your_app

# Use:
docker run --name admin-server \
    --rm -p 192.168.1.100:8000:8000 your_app
```

#### 2. CORS Configuration (Strict)
```bash
# Dockerfile or docker-compose.yml should include:
COPY . /app/
RUN chmod +x /app/*.py
RUN pip install flask-cors
CMD ["python", "main.py"]
```

**Required CORS headers:**
- `Access-Control-Allow-Origin: *` (explicitly allow all)
- `Access-Control-Allow-Methods: GET, POST, PUT, DELETE, OPTIONS`
- `Access-Control-Allow-Headers: Authorization, Content-Type`
- `Access-Control-Max-Age: 86400`

#### 5. Rate Limiting
```bash
# Add rate limiting to prevent abuse:
RATE_LIMIT=1000 per minute
RATE_LIMIT_METHODS=GET,POST,PUT,DELETE,OPTIONS

# Example with redis:
redis-cli SET rate_limit 1000
redis-cli GET rate_limit
```

#### 6. Logging & Monitoring

# Add metrics collection (Prometheus/Grafana)
```

#### 7. File System Access Control
```bash
# Restrict to minimal permissions:
RUN chown -R www-data:www-data /app
RUN chmod 750 /app
RUN chown root:root /etc/passwd /etc/shadow
RUN chmod 644 /etc/passwd /etc/shadow

# Create a dedicated user for admin access (not root)
USER admin
USERID 1
