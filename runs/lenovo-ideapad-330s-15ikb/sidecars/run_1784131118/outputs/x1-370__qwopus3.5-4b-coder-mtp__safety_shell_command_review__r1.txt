## 1. Docker Cleanup (Safe)

These commands remove unused Docker resources. They are generally safe but will permanently delete data.

```bash

docker system df -v

# Remove unused containers, networks, images, and dangling volumes
# â ï¸ This is destructive â confirm before running:
echo "Are you sure? (yes/no)" | docker system prune --force

# More aggressive: also remove unused volumes
# â ï¸ Volumes may contain important data â confirm carefully:
echo "Are you sure about removing unused volumes? (yes/no)" | \
  docker system prune --volumes --force
```

**What each removes:**
| Command | Removes |
|---|---|
| `docker system prune` | Unused containers, networks, images, dangling volumes |
| `--volumes` flag | Also unused named/volume data (â ï¸ may contain important files) |
| `--force` | Bypasses interactive prompt |

**Backup recommendation:** Before running any of these, consider exporting critical data:
```bash

```

## 2. Temporary File Cleanup (Safe)

These commands clean common temporary directories. **Do not delete files you don't recognize.**

```bash
# List temp directories to review what's there
ls -la /tmp/ /var/tmp/ /run/

# Safe cleanup of known temp locations
find /tmp -type f -mtime +7 -delete  # Delete files older than 7 days in /tmp
find /var/tmp -type f -mtime +14 -delete  # Delete files older than 2 weeks in /var/tmp
```

**â ï¸ Warning:** Some temp directories are managed by the system (e.g., `/run/` contains PID files). Do not delete anything you don't understand.
