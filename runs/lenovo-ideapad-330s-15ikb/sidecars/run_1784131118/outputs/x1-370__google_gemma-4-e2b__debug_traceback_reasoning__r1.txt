## Root Cause

The error `TypeError: 'NoneType' object is not subscriptable` occurs because one of the intermediate dictionary lookups failed to find a key, resulting in a value of `None`. Specifically, it is highly likely that either `payload['user']` is `None`, or `payload['user']['id']` is `None`, and the script attempts to access a key on that `None` object.

## Safe Fix

Use `.get()` methods to safely access nested dictionary keys, providing default values (like an empty dictionary `{}`) if a key is missing, preventing the script from crashing when data is incomplete.

```python
# Original problematic line: user_id = payload['user']['id']

# Safe Fix: Use .get() for safe navigation
user_data = payload.get('user', {})  # Get 'user' or an empty dict if missing
user_id = user_data.get('id')        # Get 'id' from the result, defaults to None if not found

# Or, more concisely:
user_id = payload.get('user', {}).get('id')
```
