
**Root Cause**  
The error `TypeError: 'NoneType' object is not subscriptable` means that the expression `payload['user']['id']` tried to index a value of type **None**. This happens when `payload.get('user')` returns `None` (e.g., because the incoming request body was empty, malformed JSON, or the API returned an error before populating the payload). The code assumes that every valid payload contains a nonânull `'user'` object with an `'id'` field.

def get_user_id(payload: dict) -> int | None:
    """
    Safely extract the user ID from a request payload.
    Returns None if the ID cannot be determined, but never raises TypeError.
    """
    # 1ï¸â£ Ensure 'user' exists and is a dictionary
    user = payload.get('user')
    if not isinstance(user, dict):
        raise ValueError("Missing or malformed 'user' field in payload")
    
    # 2ï¸â£ Extract the id safely; return None when it's missing/absent
    return user.get('id')
