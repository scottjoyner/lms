| # | Item | Gap | Deliverable |
|---|------|-----|-------------|
| P0-1 | **Auth middleware** | No auth = unauthenticated access to all endpoints, especially shell commands | JWT/OAuth2 + FastAPI `Depends` auth decorator; protected routes (`@router.post("/shell")`) |

## Security Checklist (P0/P1.1)

- [ ] All endpoints require auth except `/health` and `/metrics`
- [ ] Shell endpoint uses `subprocess.run([...])`, not `os.system()` or `exec()`
- [ ] Input validation on all parameters (`pydantic`)
- [ ] No stack traces in production responses
- [ ] Secrets stored via environment variables (no `.env` in repo)
