

## Root Cause

The error occurs because the `payload` dictionary contains a `'user'` key, but its value is `None`. The script attempts to access `.id()` on this `None` object, which raises a `TypeError: 'NoneType' object is not subscriptable`. This typically happens when an API returns no user data for that request.

## Safe Fix

Replace the direct access with a safe lookup method:

```python
user_id = payload.get('user', {}).get('id')  # or payload.get('user_id')
```

This uses `.get()` to handle missing keys gracefully, returning `None` instead of raising an error.
