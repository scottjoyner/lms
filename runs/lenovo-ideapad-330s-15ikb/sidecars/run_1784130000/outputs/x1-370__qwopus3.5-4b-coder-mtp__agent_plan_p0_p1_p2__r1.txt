### Task P0-1: User Authentication (JWT/OAuth2)

**Description:** Implement secure user authentication using JWT tokens with refresh token rotation, supporting password-based login and OAuth2 provider integration.

| Sub-task | Description |
|---|---|
| **P0-1-A** | Create `User` model with hashed passwords, email verification status, and role field |
| **P0-1-B** | Implement JWT token generation (access + refresh tokens) with 15min / 24h expiry |
| **P0-1-C** | Build password hashing using Argon2 or bcrypt (Argon2 preferred for security) |
| **P0-1-D** | Add OAuth2 provider support (Google/GitHub) with PKCE flow |
| **P0-1-E** | Implement token validation middleware at all protected routes |
