## Safe Deployment Checklist

### 1. Network Binding Restriction
```bash
# â DO NOT: Bind to 0.0.0.0:8000
# SHOULD: Bind to localhost only (or specific trusted networks)

# Example using Docker Compose:
services:
  admin-server:
    image: your-fastapi-app:latest
    container_name: my-admin-server
    # Use: --network=host or --network=private
    volumes:
      - ./config:/app/config
      - /etc/hosts:/etc/hosts
```

### 2. CORS Restriction
```bash
# â DO NOT: Allow CORS from * (wildcard)
# SHOULD: Restrict to specific domains or disable CORS entirely

# Example with Docker Compose:
services:
  admin-server:
    container_name: my-admin-server
    # Disable CORS by default, add explicit allow list if needed
    environment:
      - CORS_ORIGIN=127.0.0.1
      - CORS_ORIGINS=http://localhost:8000
```

### 3. Secure Token Storage
```bash
# â DO NOT: Store token in README (plain text)
# SHOULD: Use secure storage mechanisms

# Options:
- Environment variables (Docker Compose, Kubernetes Secrets)
- AWS Secrets Manager / Azure Key Vault
- HashiCorp Vault
- Encrypted file system mount with proper permissions
```

### 4. Non-Root Container Execution
```bash
# â DO NOT: Run as root in container
# SHOULD: Use non-root user for container execution

# Example using Docker Compose:

  admin-server:
    image: your-fastapi-app:latest
    # Use --privileged flag if absolutely necessary (rare)
    # Otherwise, use a non-root user with proper permissions
    command: python -m fastapi app.py
    environment:
      - SECRET_KEY=your-secret-key-here
```
