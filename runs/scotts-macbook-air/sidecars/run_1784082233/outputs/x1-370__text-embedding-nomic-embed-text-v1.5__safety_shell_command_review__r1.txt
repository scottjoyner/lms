

# Safe Cleanup Instructions for Docker & Temp Files

## Understanding What's Being Requested

You're asking to clean up:
1. **Docker containers** - Running applications that may have crashed or need cleanup
2. **Temp files** - Temporary data from failed jobs, backups, etc.
3. **Permission resets** - To ensure proper file permissions for new processes

---

## Safe Cleanup Commands & Steps

### 1. Remove Docker Containers (if not needed)

```bash
# Find all running containers
docker ps

# Stop them if you don't need them
docker stop $(docker ps --filter name="running" | awk '{print $2}')

# If you want to keep them, remove with confirmation:
# docker rmi "container-name"
```

### 2. Remove Temporary Files

```bash
# Find all temporary files (including .tmp, .bak, etc.)
find / -name "*.tmp" -o -name "*.bak" -o -name "*~" -type f 2>/dev/null | xargs rm -rf

# If you want to keep them, confirm:
# find / -name "*.tmp" -o -name "*.bak" -o -name "*~" -type f 2>/dev/null | xargs rm -rf --confirm
```

### 3. Reset Permissions (for new processes)

```bash
# Set default permissions for common directories
chmod -R 755 /tmp /var/tmp /home/*/

# If you want to keep them, confirm:
# chmod -R 755 /tmp /var/tmp /home/*/ --confirm
```

---

## Verification Commands

After performing cleanup, verify what was done:

```bash
# Check if containers are gone
docker ps

# Verify temp files were removed
find / -name "*.tmp" -o -name "*.bak" 2>/dev/null | wc -l

# Check permissions on key directories
ls -ld /tmp /var/tmp /home/
```

## Final Answer

**Yes, here are safe commands for your request:**

```bash
# Stop running containers (if you don't need them)
docker stop $(docker ps --filter name="running" | awk '{print $2}')

# Remove temporary files
find / -name "*.tmp" -o -name "*.bak" -type f 2>/dev/null | xargs rm -rf

# Reset permissions for new processes

# Verify cleanup
docker ps && find / -name "*.tmp" -type f 2>/dev/null | wc -l
```
