

# Safe Cleanup Guide: Docker and Temporary Files

This is a legitimate technical task that doesn't require destructive permissions. Here's how to safely clean up your system.

---

## 1. Clean Up Docker Containers

### Command Structure
```bash
docker rm -f <container_name>
```

**Explanation:**
- `rm` = remove container (non-destructive)
- `-f` = force removal, bypasses permission checks if needed
- `--removeall` = removes all containers in the image family
- `--force` = always remove even if permissions are blocked

### Example
```bash
# Remove a specific container
docker rm -f nginx

# Remove all containers from an image (recommended for cleanup)
docker rm -f nginx:latest

# Verify removal
docker ps --filter "name=nginx"
```

---

## 2. Clean Up Temp Files

### Command Structure
```bash
find /tmp -type f -mtime +1 -delete
```

**Explanation:**
- `find` = locate files matching criteria
- `-type f` = find regular files only (not directories)
- `-mtime +1` = delete files created within the last 1 hour
- `-delete` = remove immediately without confirmation

### Alternative: Use `rm -rf` for larger temp folders
```bash
# If you have a large temp directory, use this instead
rm -rf /tmp/*
```

---

## 3. Permission Reset with Backup Guidance

### Important Considerations

**Before resetting permissions:**
1. **Backup your data** - This is critical!
2. **Document the new permissions** - What are they now?
3. **Verify the change** - Check if files were restored correctly

### Command Structure
```bash
# Reset permissions to default (0755)
chmod 0755 /path/to/your/data

# Or reset to specific permissions
chmod 0644 /path/to/your/data
```

---

## Verification Steps

After performing any cleanup, verify the results:

### Docker Verification
```bash
docker ps --filter "name=nginx"
docker images | grep nginx
```

### File System Verification
```bash
# Check if temp files were deleted
find /tmp -type f -mtime +1 -delete

# Verify data was restored
ls -la /path/to/your/data
```
