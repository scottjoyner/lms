## P1.2 - Infrastructure & Deployment

### 3. Docker Setup

**Dockerfile Requirements:**
```bash
# FastAPI backend
FROM python:3.9-slim
WORKDIR /app
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt
COPY . .
EXPOSE 8000
CMD ["python", "main.py"]
```

**Docker Compose:**
- `backend`: FastAPI application with PostgreSQL
- `frontend`: React dashboard (optional, can be separate container)

### 3. Healthcheck Implementation

```bash
# Python health check script
#!/usr/bin/env python
import requests
from fastapi.testclient import TestClient

app = FastAPI()
client = TestClient(app)

@app.get("/health")
async def health_check():
    response = client.get("http://localhost:8000/health")
    return {"status": "healthy", "timestamp": response.json()["data"]}
```

### 3. CI/CD Pipeline Setup

**GitHub Actions workflow:**

```yaml
# .github/workflows/ci.yml
name: Continuous Integration

on: [push, pull_request]

jobs:
  test:
    runs-on: ubuntu-latest
    
    steps:
      - uses: actions/checkout@v4
      
      - name: Set up Python
        uses: actions/setup-python@v5
        with:
          python-version: '3.9'
      
      - name: Install dependencies
        run: |
          pip install --upgrade pip
          pip install pytest pytest-cov
          
      - name: Run unit tests
        run: |
          pytest tests/
          pytest --cov=backend --cov-report=html
      
      - name: Run integration tests
        run: |
          pytest tests/integration/
      
      - name: Lint code
        run: |
          flake8 . --count=true --ignore =pyi,pydoc,flake8_compliant
          pylint backend --max-line-length=120
      
      - name: Deploy to Docker Hub
        uses: docker/build-push-action@v5
        with:
          context: ./backend
          push: true
          tags: fastapi-backend:v1.0.0
```
