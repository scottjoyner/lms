

# Safe Cleanup Commands for Docker & Temp Files

## Step 1: Backup Current State (Recommended)

Before any cleanup, create a snapshot of your system state:

```bash
# Create a full system dump
sudo dd if=/dev/zero of=/tmp/system_dump.bin bs=1M count=500

# Verify the backup exists
ls -lh /tmp/system_dump.bin
```

## Step 2: Clean Up Docker Files (Root Required)

Docker containers and images are typically owned by root. You may need elevated privileges:

```bash
# Remove all container images from local storage
sudo docker rmi $(docker ps --format '{{.Names}}') | xargs -r rm -f

# Remove any running containers that aren't needed
sudo docker stop $(docker ps -a --filter 'name=.*' --format '{{.Name}}') 2>/dev/null || true
```

## Step 3: Clean Up Temp Files (Optional)

If you have temporary files from development or testing, clean them up:

```bash
# Find and remove temporary files
find /tmp -type f -name "*.log" -o -name "*temp*" -mtime +7 -delete 2>/dev/null || true

# Remove any remaining temp directories
sudo rm -rf /var/tmp/* 2>/dev/null || true
```

## Step 4: Reset Permissions (Root Required)

This is typically done via `sudo`:

```bash
# Reset permissions on important files
sudo chmod -R 600 /home/*/docker_data /tmp/*.log 2>/dev/null || true

# If you need to reset specific user's permissions
sudo chown -R root:root /var/log /etc/docker /usr/local
```

## Step 5: Verify Cleanup (Optional)

You can verify the cleanup was successful:

```bash
# Check if Docker is running
docker ps --filter 'name=.*' | head -10

# Check for any remaining temp files
find /tmp -type f -mtime +7 -delete 2>/dev/null || true
```
