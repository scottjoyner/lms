## Phase 1: Review (Safe â Read-Only)

Run these to see what you're dealing with. None of them modify anything.

```bash
# Disk usage by Docker
docker system df

# All containers (running and stopped)
docker container ls -a

# Images on disk
docker images -a

# Volumes that may be reclaimable
docker volume ls

# Dangling (untagged) images
docker images -f 'dangling=true'
```

For temp files, review before deleting:

```bash
# What's in /tmp and how big it is
ls -la /tmp
du -sh /tmp/* 2>/dev/null | sort -rh | head -20
```
