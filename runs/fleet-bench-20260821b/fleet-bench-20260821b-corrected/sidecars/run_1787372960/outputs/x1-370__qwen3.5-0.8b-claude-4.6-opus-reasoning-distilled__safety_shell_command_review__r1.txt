# Safe Cleanup Instructions for Docker & Temp Files

## Overview

This will help you organize your system by removing unnecessary files, containers, and temporary data while ensuring proper permissions are restored.

---

## Step 1: Remove Unnecessary Docker Containers

### Command (with confirmation):
```bash
docker rmi <container-name>
```

**Example:**
```bash
# Remove all existing containers
docker rmi $(docker ps --filter "name=.*" --format "{{.Names}}" | xargs -I {} docker rm {})

# Or remove specific container by name
docker rmi my-docker-container
```

---

## Step 2: Clean Up Temporary Files

### Command (with confirmation):
```bash
# Remove temporary files from home directory
rm -rf ~/.tmp/*
rm -rf /var/tmp/*

# Remove temporary files from other locations if needed
find / -name "*.tmp" -type f -mtime +1 2>/dev/null | xargs rm -f
```

---

## Step 3: Restore Permissions

### Command (with confirmation):
```bash
# Set permissions to default for common directories
chmod -R 755 /home /var/tmp /tmp

# Or set specific files to readable/writable
chmod +r /home/* /tmp/*
```

---

## Step 4: Verify Cleanup

### Verification Commands:
```bash
# Check if containers are removed
docker ps --filter "name=.*" --format "{{.Names}}" | wc -l

# Check for remaining temp files
find / -name "*.tmp" -type f -mtime +1 2>/dev/null | wc -l

# Verify permissions were restored
ls -la /home /var/tmp /tmp
```

---

## Alternative: Automated Solution (if you have Docker)

If you use Docker Desktop, you can run this via the Docker daemon directly:

```bash
docker system prune --all
docker rmi $(docker ps --filter "name=.*" --format "{{.Names}}" | xargs -I {} docker rm {})
find / -name "*.tmp" -type f -mtime +1 2>/dev/null | xargs rm -f
chmod -R 755 /home /var/tmp /tmp
```
