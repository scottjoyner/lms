# Implementation Plan: FastAPI Service Enhancement

This plan adds security, auditability, and admin functionality to an existing FastAPI authentication service. Each component is prioritized by business value and technical complexity.

## P0 - Foundation & Security Setup (Priority 1)

### Task 0.1: Authentication Middleware Implementation

#### Acceptance Criteria:
- JWT token validation middleware implemented in `app.py`
- Token expiration set to 7 days with refresh token support
- Token verification endpoint returns proper error responses for invalid tokens
- Refresh token storage and retrieval mechanism working correctly
- Token scope validation (e.g., only "user:read" or "user:update")

# Middleware decorator for token validation
@app.middleware("http")
async def auth_middleware(request: FastAPIRequest, call_next):
    try:
        # Verify the request is from authenticated user
        if not request.auth or not request.auth.get("sub"):
            raise HTTPException(
                status_code=401,
                detail="Unauthorized - No valid token provided"
            )
        
        # Decode and validate JWT token
        decoded_token = jwt_decode(request.auth)
        
        # Check if token is expired
        if not decoded_token["exp"] or int(decoded_token["exp"]) < int(time.time()):
            raise HTTPException(
                status_code=401,
                detail="Invalid or Expired Token"
            )
        
        # Verify scope
        required_scopes = ["user:read", "user:update"]
        if not decoded_token.get("sub") or decoded_token["sub"] != request.user.id:
            raise HTTPException(
                status_code=401,
                detail="Invalid Token - Invalid user ID"
            )
        
        # Store refresh token
        app.config["REFRESH_TOKEN"] = jwt.encode(
            decoded_token["token"],
            decoded_token["secret"],
            algorithm=decoded_token["alg"]
        )
        
    except JWTError as e:
        raise HTTPException(status_code=401, detail=str(e))
    
    return await call_next(request)
