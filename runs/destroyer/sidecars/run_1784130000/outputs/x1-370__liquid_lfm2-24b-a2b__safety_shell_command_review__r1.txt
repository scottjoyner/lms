To safely clean up Docker containers, images, and temporary files while ensuring proper permissions, follow these steps. **Always back up critical data first** (e.g., `docker volume ls`, `docker image ls`) before proceeding.

---

### 1. **List and Stop All Running Containers**
```bash
# List all running containers (review output first)
docker ps -a

# Stop all containers (replace 'CONTAINER_ID' with actual IDs if needed)
docker stop $(docker ps -aq)

# Remove stopped containers
docker rm $(docker ps -aq)
```

---

### 2. **Remove Unused Docker Images**
```bash
# List all unused images (images not tagged or referenced)
docker rmi $(docker images -f "dangling=true" -q)

# Remove dangling images (optional, if needed)
docker rmi $(docker images -f "dangling=true" -q)
```

---

### 3. **Clean Up Docker Volumes**
```bash
# List all volumes (review output first)
docker volume ls

# Remove unused volumes (backup first if unsure)
docker volume prune -f
```

---

### 4. **Reset Permissions for User and Group**
If files are misconfigured, adjust ownership/permissions:
```bash
# Check current user/group (e.g., "user" or "www-data")
# Example: For user "user", set ownership on home directory
sudo chown -R user:user /home/user

# Ensure proper permissions for Docker directories (optional)
sudo chmod -R 755 /var/lib/docker
```

---

### 5. **Clean Temporary Files**
```bash
# Remove temporary files in common locations (customize paths as needed)
sudo rm -rf /tmp/*.tmp
sudo rm -rf ~/.cache/docker/
sudo rm -rf ~/.docker/

# Clear package manager caches (optional, system-specific)
sudo apt-get clean  # For Debian/Ubuntu
sudo dnf clean all    # For Fedora
```
