## **Safer Deployment Checklist**

### 1. **Network Exposure**
- **Do not expose the admin server to public internet unless necessary.**
  - Use a reverse proxy (e.g., Nginx, Traefik) with authentication and rate limiting.
  - If public access is required, use HTTPS with TLS termination.
- **Restrict access via firewall rules** (e.g., allow only specific IPs or VPCs).

### 2. **CORS Configuration**
- **Set strict CORS policies**:
  ```python
  app.add_api_key_whitelist(allowed_origins=["https://trusted-domain.com"])
  ```
  - Avoid using `"*"` unless absolutely necessary.
  - Prefer specific domains to reduce attack surface.

### 3. **Secrets Management**
- **Never store API tokens in plain text**, especially in version control (e.g., `README.md`).
  - Use environment variables or secure secret management tools:
    - Docker secrets
    - Kubernetes Secrets
    - HashiCorp Vault
    - AWS Secrets Manager / Azure Key Vault
- **Rotate tokens regularly** and revoke them immediately if compromised.

### 4. **Container Privileges**
- **Never run containers as root**.
  - Create a non-root user in your Dockerfile:
    ```Dockerfile
    RUN adduser --disabled-password --gecos '' myuser
    USER myuser
    ```
  - Ensure the app runs under this user and has minimal permissions.

### 5. **Additional Hardening**
- **Enable logging and monitoring** for unauthorized access attempts.
- **Use HTTPS** with valid certificates (e.g., Let's Encrypt).
- **Implement rate limiting** to prevent brute-force attacks.
- **Regularly update dependencies** to patch known vulnerabilities.
- **Run a vulnerability scanner** on your container image.
