## Root Cause

`payload['user']['id']` fails because one of these is `None`:
- `payload` itself (e.g., response body was empty)
- `payload['user']` (key exists but value is `null`)
- The result of a prior operation that returned `None` and got reassigned

## Safe Fix

Use `.get()` with defaults to short-circuit before subscripting:

```python
# Line 42 â safe navigation
user_id = payload.get('user', {}).get('id') if payload else None
```

Or, for explicit early exit:

```python
if not payload or 'user' not in payload or not payload['user']:
    return  # handle missing user gracefully
user_id = payload['user']['id']
```
