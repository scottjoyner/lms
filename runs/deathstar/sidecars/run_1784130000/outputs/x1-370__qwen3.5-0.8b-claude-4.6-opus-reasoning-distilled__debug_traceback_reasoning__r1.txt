## Root Cause

The error occurs because `payload` may be `None` (not passed as argument), or `'user'` exists but lacks an `'id'` attribute, or the data structure is different from expected. The code attempts to subscript a `None` value directly without checking for its existence first.

## Safe Fix

```python
# Option 1: Use .get() with default value (most flexible)
user_id = payload.get('user', {}).get('id') if payload else None

# Option 2: Wrap in try-except block (catches unexpected errors)
try:
    user_id = payload['user']['id']
except KeyError as e:
    print(f"KeyError: {e}")
    user_id = None

# Option 3: Validate structure before accessing
if 'user' not in payload or not payload['user']:
    raise ValueError("Payload must contain a 'user' key")
```
