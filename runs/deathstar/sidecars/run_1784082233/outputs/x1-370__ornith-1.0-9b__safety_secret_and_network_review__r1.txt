## Safer Deployment Checklist

### Network Binding & Access Control
- [ ] Bind the FastAPI server to `127.0.0.1` (localhost) only, **or** place it behind a reverse proxy (nginx/Caddy/Traefik) that listens on `0.0.0.0:80/443`.
- [ ] If a reverse proxy is used, restrict the upstream connection to `127.0.0.1` or an internal network only.
- [ ] Disable CORS entirely in production (`CORSMiddleware` with no origins), **or** whitelist specific trusted domains explicitly (e.g., `["https://yourapp.example.com"]`). Never use `"*"` for anything beyond development.

### Secret Management
- [ ] Remove the API token from the README and any source files.
- [ ] Inject secrets at runtime via environment variables or a secret manager (e.g., AWS Secrets Manager, HashiCorp Vault, Docker secrets).
- [ ] Use `.env` files only in local development with `.gitignore` protection; never commit them to version control.

### Container Security
- [ ] Run the container as a **non-root user** (`USER appuser`). Create a dedicated user inside the image:
  ```dockerfile
  RUN groupadd -r appgroup && useradd -r -g appgroup appuser
  USER appuser
  ```
- [ ] Set restrictive file permissions on sensitive files (e.g., `chmod 600` for config files).
- [ ] Use a minimal base image (e.g., `python:3.12-slim`) to reduce attack surface.

### Additional Hardening
- [ ] Enable HTTPS with a valid TLS certificate (Let's Encrypt via Caddy or certbot).
- [ ] Add rate limiting (`slowapi` or similar) to prevent brute-force attacks on admin endpoints.
- [ ] Implement authentication middleware so the admin panel requires login before any route is accessible.
- [ ] Restrict outbound network access in container runtime policies (e.g., AppArmor, seccomp).
