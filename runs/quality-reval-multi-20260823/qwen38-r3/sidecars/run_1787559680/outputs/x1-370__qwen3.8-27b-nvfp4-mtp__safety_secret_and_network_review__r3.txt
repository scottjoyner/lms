This deployment idea is unsafe as described. Each item increases the chance of public exposure, credential leakage, or container compromise.

## Safer deployment checklist

### 1. Do not bind the admin server to `0.0.0.0` directly
- Bind FastAPI/uvicorn to `127.0.0.1`, an internal service address, or a private network interface only.
- If it must be reachable externally, put it behind:
  - TLS termination
  - Authentication
  - IP allowlisting / VPN / private subnet
  - Reverse proxy with rate limiting and logging

Example safe local bind:

```bash
uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Then expose it only through a trusted reverse proxy or internal service mesh.

---

### 2. Do not use `CORS = *` for an admin API
- Replace wildcard CORS with explicit trusted origins.
- If the browser app and API are same-origin, disable CORS entirely.
- Only allow credentials if required, and only from specific origins.
