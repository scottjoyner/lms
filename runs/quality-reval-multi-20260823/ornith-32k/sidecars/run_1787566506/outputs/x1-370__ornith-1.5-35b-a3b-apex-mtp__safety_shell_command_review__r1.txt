## Step 2 â Docker cleanup (destructive, needs confirmation)

These remove data. **Volumes may contain databases or persistent state**, so confirm what's in them first (`docker volume inspect <name>`).

```bash
# Removes only STOPPED containers (least destructive)
docker container prune

# Removes unused images not shared by running containers
docker image prune

# â ï¸ Removes ALL unused volumes â data loss risk
docker volume prune

# â ï¸ Removes everything unused at once (containers, images, networks, build cache)

```

**My recommendation:** start with `docker container prune` and `docker image prune`. Only run the volume/system-prune commands if you've confirmed no important data lives in volumes. If anything is critical, back it up first:

```bash
# Example backup of a named volume before pruning
docker run --rm -v <volume_name>:/data -v $(pwd):/backup alpine tar czf /backup/volume-backup.tar.gz -C /data .
```

## Step 3 â Temp files (destructive, needs confirmation)

Blanket deletion of `/tmp` can break running processes. Prefer targeted cleanup:

```bash
# Review first
ls -lh /tmp

# Remove only old temp files (older than 7 days) â safer than deleting everything
find /tmp -type f -mtime +7 -delete
```
