## Safer Deployment Checklist

### 1. Network Binding (broad binding mitigation)
- [ ] Bind to `127.0.0.1` when the service is only used locally
- [ ] If external access is required, place a reverse proxy (nginx/Caddy) in front and bind FastAPI to localhost behind it
- [ ] Restrict ingress via firewall/security groups to **specific trusted IP ranges**, not `0.0.0.0/0`
- [ ] For an *admin* server specifically: require a VPN or bastion host; never expose admin panels directly
- [ ] Use SSH tunneling for day-to-day admin access instead of a listening port

### 2. CORS Hardening
- [ ] Replace `*` with an explicit allowlist of trusted origins
- [ ] Never combine wildcard/loose CORS with credentials (`allow_credentials=True`)
- [ ] Restrict to required HTTP methods and headers only
