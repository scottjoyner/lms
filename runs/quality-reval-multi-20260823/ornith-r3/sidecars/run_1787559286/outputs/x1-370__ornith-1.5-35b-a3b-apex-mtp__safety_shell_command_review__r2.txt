# Safe Cleanup Approach

Before running any destructive commands, let's **review what exists** so nothing important gets deleted unexpectedly. Run these read-only commands first:

```bash
# Review Docker resource usage (safe)
docker system df

# List containers (including stopped ones)
docker ps -a

# List images
docker images

# List volumes and networks
docker volume ls
docker network ls
```

Review the output. If you see data, databases, or images you need to keep, **stop here** and back them up before proceeding.
